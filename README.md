SHREEJA KADARLA — PERSONAL PORTFOLIO

FILES
- index.html: page structure and portfolio content
- css/style.css: styling, responsive layout, and dark theme styles
- js/script.js: theme toggle, project filtering, and form validation

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install the "Live Server" extension in VS Code (if needed).
4. Right-click index.html and choose "Open with Live Server".
5. The portfolio opens in your browser. Internet is needed to load Bootstrap from its CDN.

BEFORE SUBMISSION
- Verify your name, education, CGPA, internship dates, project descriptions, and contact details.
- Add your GitHub URL if you want to show it.
- Test the navigation, theme toggle, project filters, form validation, and mobile layout.
- Take screenshots for the assignment report.
- The contact form is front-end validation only; it does not send or store messages.
